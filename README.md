# Luma

Luma is a local-first personal attention tracker. It combines upcoming deadlines and recurring habits into one calm view that answers: what needs my attention now?

The current build includes:

- deadline CRUD, completion, urgency profiles, time-remaining copy, and local reminders;
- daily, selected-weekday, and weekly-frequency habits;
- quick boolean and numeric progress logging;
- weekly reliability, streaks, completion totals, and lightweight derived XP;
- a unified Attention feed generated by tested domain logic;
- a Gluestack UI v5 component system styled with UniWind and adaptive light/dark themes;
- SQLite migrations and notification reconciliation with no account or backend.

## Requirements

- Node.js 20 or newer
- Xcode/iOS Simulator or Android Studio for native development
- A development build or physical device for realistic notification testing

## Run

```bash
npm install
npm start
```

Then choose iOS or Android from Expo. Local notification behavior should be verified in a native development build:

```bash
npx expo run:ios
# or
npx expo run:android
```

Notification permission is not requested at launch. Luma explains the need after the first item with a reminder is saved.

## Development commands

```bash
npm run typecheck
npm run lint
npm test
npx expo-doctor
npx expo export --platform ios
```

In development builds, Settings can add sample data only when the database is empty. Production builds never seed fake data.

## Project layout

- `app/` — Expo Router screens and navigation
- `src/domain/` — pure deadline, habit, attention, and notification rules
- `src/db/` — SQLite migrations and repositories
- `src/services/` — orchestration, attention loading, notifications, and development seed
- `src/features/` and `src/components/` — forms and reusable UI
- `__tests__/` — critical date and business-logic tests
- `docs/` — architecture and product roadmap

See [Architecture](docs/ARCHITECTURE.md) and [Roadmap](docs/ROADMAP.md).
